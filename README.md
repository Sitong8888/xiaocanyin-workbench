# 小餐饮爆品与赛道筛选工作台

一个面向「小餐饮创业 / 品类选择 / 爆品挖掘」的**移动端优先、平板自适应**可交互 Web 工作台。纯静态、零外部依赖，可直接部署到 GitHub Pages。

> 在线访问：**https://sitong8888.github.io/xiaocanyin-workbench/**

## 功能特性

### 1. 多级关联数据模型
- **行业主表 `INDUSTRY_TREE`**：6 个一级赛道（茶饮咖啡 / 小吃快餐 / 烘焙甜品 / 火锅串串 / 夜宵烧烤 / 轻食沙拉），向下展开 **31 个三级细分行业**，含 `id / name / level(1~3) / parentId` 父子关联，支持 1～3 级层级检索。
- **品类全景数据表 `CATEGORY_ANALYTICS`**：以 `level3Id` 关联三级行业，沉淀市场规模、同比增长、竞争烈度、渗透率、客单价、复购率、TOP 品牌 + 市占、人群画像、近 12 个月趋势、蓝海/红海标签、商品全景等分析指标。

### 2. 移动端 / 平板端 UI
- **顶部级联筛选**：两组联动下拉（主分析对象 A / 对比分析对象 B），一级→二级→三级逐级联动。
- **KPI 核心指标卡**：市场规模、同比增长、渗透率、客单价、复购率（手机端横滑 Swiper，减少长页滚动）。
- **双向交叉矩阵 / 雷达图**：6 维度对比 A/B 两组差异。
- **趋势折线图**：近 12 个月两组规模走向对比。

### 3. 战略空位分析（顾均辉空位表模型）
- 选中三级行业即展示 4 个核心板块：**核心竞争对手及占据心智 / 客户未被满足的痛点 / 竞品的固有弱点 / 战略空位与切入点（核心结论）**。
- 空位分类标签：👥 人群空位 / 💰 价格空位 / 🕒 场景空位 / ✨ 特性空位。
- **双赛道空位对比**：A/B 并排展示 4 维度 + 各自空位标签，并自动生成差异洞察。

### 4. 交互体验
- 横滑卡片、点击「下钻」弹出品牌与商品全景抽屉。
- 蓝海 / 红海 / 高潜 / 平稳以颜色徽标贯穿筛选、KPI 与下钻面板。

## 目录结构

```
.
├── index.html          # 应用入口
├── css/
│   └── styles.css      # 移动端优先、平板自适应的响应式样式
├── js/
│   ├── data.js         # 数据模型（行业主表 + 品类全景 + 战略空位表）
│   └── app.js          # 交互逻辑、级联联动、SVG 图表、下钻、空位面板
└── .nojekyll           # 适配 GitHub Pages（避免 Jekyll 处理）
```

## 本地运行

```bash
# 方式一：直接用浏览器打开
open index.html

# 方式二：本地静态服务器
python -m http.server 8080
# 然后访问 http://localhost:8080/
```

## 部署（GitHub Pages）

```bash

```

## 技术栈

- 纯 HTML / CSS / 原生 JavaScript（ES5+），无框架、无构建步骤。
- 图表使用内联 SVG 手绘（雷达图 / 折线图 / 矩阵），无第三方图表库。
- 数据由确定性伪随机生成器（`mulberry32`）生成，刷新稳定。
